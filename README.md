# PnR-flow-for-MIPS-16-
RTL-to-GDSII physical design of MIPS-16 processor with T-shaped floorplan. Achieved 500 MHz frequency (2× improvement) using mesh-based power distribution and optimized CTS parameters (max fanout=5, transition=0.3ns) with only 2.1% area increase. Final design meets all signoff requirements including IR drop &lt;2% and formality checks.
